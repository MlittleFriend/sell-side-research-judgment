# 卖方研究分析与判断（Codex Skill）

这是一项可复用的研究方法技能，适用于卖方报告、宏观专题、行业公司研究、策略展望，以及大纲和正文的审稿。

它要求先检验论证逻辑，再系统核对可取得的数据与反证，最后形成明确、合理、可检验的专业判断。它强调敢于下结论，同时区分已观察的事实、经济机制推断和未来预测。

## 安装

将本仓库克隆或下载到个人 Codex 技能目录，确保路径为：

```text
~/.codex/skills/sell-side-research-judgment/SKILL.md
```

完整保留 `agents/` 和 `references/` 目录。安装后在新的 Codex 对话中使用；可明确提及“卖方研究分析与判断”，也可在适用的研究任务中让 Codex 自动调用。

## 内容

- `SKILL.md`：原则、证据检验、结论形成与审稿要求。
- `references/judgment-examples.md`：不同研究场景下的判断与改写示例；示例不是真实数据，也不是预设市场观点。
- `agents/openai.yaml`：技能显示信息。

本技能只规定分析方法，不提供投资建议或可直接引用的数据。具体报告的事实、来源、口径与结论仍须逐项核验。
